# ResumeMatch

Aplicación web en español para comparar un currículum con una oferta laboral. El análisis se realiza en el navegador y no se envía ni almacena el contenido.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

Admite texto pegado y archivos PDF con texto seleccionable o TXT. El resultado detecta habilidades clave mencionadas en ambos textos y ofrece una guía orientativa para adaptar la postulación.
